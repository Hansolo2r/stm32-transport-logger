连接设备

  1. 打开JDY-16和手机蓝牙。
  2. 在iPhone的Bluefy中打开本页面。
  3. 点击“连接设备”，选择JDY-16。

数据说明

运动次数
设备从静止进入持续运动的累计次数。
碰撞次数
加速度超过碰撞阈值的累计次数。
会话
每次重新上电形成一个新会话。
时间
当前会话启动后的经过时间，不是日历时间。

记录管理

“暂停记录”会停止新增日志和事件计数，但保持实时显示；“在线预览记录”读取最近100条；“下载完整CSV”导出Flash中的全部简化记录；“开始新记录”会清空旧数据。

设备休眠

休眠会关闭OLED并暂停STM32采集，但保持蓝牙连接。按钮会变成“唤醒设备”，点击即可恢复；Reset或重新上电也可以恢复。这不是物理断电，蓝牙模块仍会继续耗电。
